# 🌊 MarineGuard AI ELITE

Production-grade underwater marine species detection system using YOLOv8 and FastAPI.

## Features
- Real-time marine species detection
- FastAPI backend
- YOLOv8 inference
- Structured logging
- Deployment-ready Docker setup
- ONNX export support

## Tech Stack
- Python
- YOLOv8
- FastAPI
- OpenCV
- Docker

## Run

```bash
pip install -r requirements.txt
uvicorn backend.main:app --reload
